# To-Do List App

## Project Overview
The To-Do List App is a simple Python project that helps users manage their daily tasks. Users can add new tasks, view their tasks, mark tasks as completed, and delete tasks.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Simple menu-based interface

## Technologies Used
- Python 3

## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or Command Prompt.
4. Run the following command:

```bash
python todo_list.py
```
